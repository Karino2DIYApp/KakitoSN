# Supernote用漢字書き取りアプリ

漢字が書けなかった時にこれに登録して練習する。BOOX用に作った漢字書き取りアプリのSupernote用fork。

![screencast](https://raw.githubusercontent.com/Karino2DIYApp/KakitoSN/refs/heads/main/misc/Kakito_1.gif)

## フォント

本アプリでは、[Yuji Syuku](https://fonts.google.com/specimen/Yuji+Syuku) (SIL Open Font License 1.1) を使用しています。
